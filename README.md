## ⭐ Featured Project

### [kubectl-prof](https://github.com/josepdcs/kubectl-prof)

**Profile your Kubernetes applications with minimal overhead and zero modifications.**

An open-source `kubectl` plugin to profile and diagnose applications running in Kubernetes environments without modifying application code or restarting pods.

Key capabilities:

- 🔬 **Multi-language profiling:** Java, Go, Python, Ruby, Node.js, Rust, C/C++, PHP and .NET.
- ⚡ **Low-overhead profiling:** Minimize the impact on running applications.
- 🧠 **eBPF & pprof:** Kernel-level profiling and Go runtime diagnostics.
- 🔥 **FlameGraphs:** Visualize CPU usage, memory allocations and performance bottlenecks.
- 📊 **Advanced diagnostics:** JFR recordings, heap dumps, thread dumps and other profiling outputs.
- ☸️ **Kubernetes-native:** Profile applications directly inside Kubernetes clusters.
